# 1_General_Kinetic_Analysis
Generalised code of thesis work used to determine rate constants.

# Info
This is code that I generalised so that it can run through kinetic data in CSV files, generalised so that it may take anyone's data.

# Requirements
This just requires Python3 and the stated packages imported at the top of the notebook. 

# User Guide
The file is fairly self explanatory given the cell that takes User Changed Settings. Each run is required to be in its own CSV file, with a common naming system (e.g Run_1, Run_2 ...), and contains product conc. Make sure data is in standard units first (t=s, conc=M).
